## Two Preview entries, and which one is authoritative

Vercel resolves a preview in two scopes: the **all-branches** entry, which every preview inherits, and a **branch** entry, which overrides it for deployments from that branch. So "one answer per scope" is decided by precedence, not by deleting a row: the branch entry wins on that branch and the all-branches entry answers every other preview.

A branch entry is only justified when that branch must _differ_. The fingerprint columns decide it: an identical pair is a proven duplicate, and `hidden` means Vercel stored the value as a secret and will not decrypt it, so the pair cannot be proven equal and neither entry may be removed on a guess.
