ID What v2.0 does
APP-30 Submitting seals the answers; results open automatically when both have answered (Waiting on {name} → Results In). No separate Share button.
APP-31 All eight gap kinds, grouped as the 2024 spec groups them. Doubt Gaps, the same kinds read after first showing, are not a separate group.
APP-32 Status as icon plus word: ✓ In Synch, ≈ Small Gap, ⚑ Gap, with no red and no colour-only meaning. The four severities stay in the model.

APP-35 Not built. No congratulations email in the template register.
