v2.0 Today

Admin › CRUD & Permissions · Bundle 12

ID What v2.0 does
ADMIN-01 Admin rail gated by role and an allowlist, with a CRUD & Permissions matrix.
ADMIN-02 Admin › Console › Users.
ADMIN-03 Admin › Billing: subscription per relationship and an audited owner comp (in place of Account Bank admin).
ADMIN-04 Admin › Inbox with reply, triage and assignment; support-reply email.
ADMIN-05 Staff can edit email templates and send broadcasts. Public page copy and a blog are not editable from Admin.
ADMIN-06 Prices are configuration (a reviewed change), not an admin screen. Pricing is PM-owned. Coupons are Tentative (APP-47).
ADMIN-07 Templates, relationships, audit log, platform health, gap overview and growth model screens.

Status

ID Requirement Status Acceptance (MVP)
ADMIN-01 An internal admin app only staff can open. ★ Over-Delivered Non-admins get no admin rail and admin routes refuse them.
ADMIN-02 Staff can see and manage user accounts. ✓ Delivered Admin lists members and their relationships.
ADMIN-03 Staff can see subscription state and make grants. ✓ Delivered Admin shows plan and provider state per relationship and can comp one.
ADMIN-04 Staff can read and answer support requests. ✓ Delivered A contact-form message appears in the inbox and can be replied to.
ADMIN-05 Staff can manage website content and blog posts. ◐ Partial Staff can edit public page copy and publish posts without a deploy.
ADMIN-06 Staff can change prices and maintain coupon codes. ◐ Partial Price changes ship as config; coupons per APP-47.
ADMIN-07 Further back-office tools as needed. ★ Over-Delivered n/a

★ Over-Delivered: ADMIN-01: Admin rail gated by role and an allowlist, with a CRUD & Permissions matrix. ADMIN-07: Templates, relationships, audit log, platform health, gap overview and growth model screens.

◐/◌ Gap or Tentative: ADMIN-05. ADMIN-06.
