If a Draft Can't Be Created

A calm, honest message, and one button to try again.

Very rarely, saving a new draft fails on our side. When it does, you should know three things: nothing was sent, nothing was charged, and you can try again. This screen says exactly that, instead of a blank page or a loop back to Stage 1.

At a Glance
Heading Couldn’t Create This Draft
Body Try again shortly. Nothing was sent and nothing was charged
Actions Try Again · Back to My Relationships
