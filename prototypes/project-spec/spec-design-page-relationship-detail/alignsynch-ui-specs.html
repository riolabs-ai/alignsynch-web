Aspects

Each Aspect asks two things: how it feels now, and how you wish it to be.

  1. How does how often you are in touch compare to what each wants?

    Left Value — Far short

    Right Value — As wanted

  2. How much does competition between you colour how you treat each other?

    Left Value — Constantly

    Right Value — Not at all

  3. When one of you needs something, how reliably does the other show up?

    Left Value — Rarely

    Right Value — Always

  4. How directly can you say a hard thing to each other?

    Left Value — Never

    Right Value — Plainly

  5. How well do you handle decisions about your parents together?

    Left Value — Avoided or fought

    Right Value — Shared and agreed

Mode and Setting

Every relationship run on this template records two things before either party answers. They are fixed at creation, and the report is read under them.

Mode
Basic Mode Basic Mode asks Feel and Wish on every Aspect.
Advanced Mode Advanced Mode asks all four — Feel, Wish, Think and Guess — so the report can also measure what each party predicted the other would answer.
Setting
Soft Small Gap (1) OK – a satisfactory Setting.
Full No Gap OK – an exceptional Setting.
The Setting is a lens over the Gaps, never a Gap: it changes no answer, and decides only what counts as aligned.

No price is shown here: a relationship's cost depends on the plan chosen when it is ready to complete, and the plan prices are on the pricing page.

    React handoff

    Use the existing RecordDetailShell, DetailBand, DetailFacts, and action panel. The proposal uses a right-hand slot on desktop. Place the template conversion panel first in its rail and before metadata in source order.

    Use the Design Standard v2.0.0 for identity colors and label treatment. Keep the shared identity structure and record hooks. Supply each record type’s label and content through its own view model.

    Check this shared layout on Relationship Template, My Template, and My Relationship. Each view keeps its own data and permitted actions. Local links open sample records and the Stage 1 or Stage 6 preview. Demo links open the corresponding live surface in a new tab. Aspect rows expand inline on the three proposed detail surfaces.

    Create Relationship acceptance criteria

    For both signed-in and signed-out visitors, Create Relationship opens Details (Stage 1) with the Brothers template selected. The flow proceeds through Details, Settings, Aspects, Account, and Invite, then returns to My Relationship. Account handles sign-in or registration when needed. Align is the ongoing relationship alignment stage.

    Verify this behavior in the app for both session states. The Stage 1 preview shows the selected template. Its demo link hands off to the real creation route.
